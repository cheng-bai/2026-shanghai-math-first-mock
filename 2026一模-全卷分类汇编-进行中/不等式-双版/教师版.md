## 1 不等式的基本性质与反例判断

<a id="2026一模-嘉定-13"></a>
### 嘉定 · 原卷第13题

**考点说明：** 不等式性质：依据负数的大小关系判断平方、乘除与倒数变换的方向。

来源：2026届上海高三一模嘉定卷，第13题。

规范化源文件：`2026届嘉定一模数学试卷 逐题解析.md`。

如果 $a < b < 0$ ，那么下列不等式中成立的是（）

- A. $\frac{a}{b} < 1$
- B. $a^2 > ab$
- C. $\frac{1}{b^2} < \frac{1}{a^2}$
- D. $\frac {1}{a} <   \frac {1}{b}$

【答案】B

【解析】

【分析】利用不等式的性质比较大小逐一判断即可.

【详解】对于 A：由 a < b < 0 得 $\frac{a}{b} > \frac{b}{b} = 1$ ，错误；
对于 B：由 a < b < 0，则有 $a \cdot a > a \cdot b$ ，即 $a^{2} > ab$ ，正确；
对于 C: 由 a < b < 0 得 -a > -b > 0，则根据不等式的性质有 $(-a)^{2} > (-b)^{2} > 0$ ，即 $a^{2} > b^{2}$ ，
由 $a^{2} > b^{2}$ 可得 $\frac{1}{a^{2}} < \frac{1}{b^{2}}$ ，错误；
对于 D: 由 a < b < 0 得 ab > 0，则 $\frac{a}{ab} < \frac{b}{ab}$ ，即 $\frac{1}{a} > \frac{1}{b}$ ，错误.
故选：B

<a id="2026一模-杨浦-13"></a>
### 杨浦 · 原卷第13题

**考点说明：** 不等式基本性质：利用已知顺序逐项比较差与和，并用反例检验乘积命题。

来源：2026届上海高三一模杨浦卷，第13题。

规范化源文件：`2026届杨浦一模数学试卷 逐题解析.md`。

已知实数 $a, b, c, d$ 满足: $a > b > c > d$ , 则下列不等式恒成立的是 ( )

- A. $a - c > b - d$
- B. $a + c > b + d$
- C. $ab > cd$
- D. $a c > b d$

【答案】B

【解析】

【分析】举出反例可判断 ACD，根据不等式的基本性质，可判断 B，进而得到答案.

【详解】对于 A，令 a=4, b=3, c=2, d=1，满足 a>b>c>d，

此时 a-c=2, b-d=2，a-c=b-d，故 A 错误；

对于 B，由 a > b, c > d ，两式相加得 $a + c > b + d$ ，故 B 正确；

对于 C，令 a=1, b=0, c=-1, d=-2，满足 a>b>c>d，

此时 ab = 0, cd = 2，ab < cd，故 C 错误；

对于D，令 $a = 1, b = -1, c = -2, d = -3$ ，满足 $a > b > c > d$

此时 $ac = -2, bd = 3$ ， $ac < bd$ ，故D错误.

故选：B

<a id="2026一模-金山-13"></a>
### 金山 · 原卷第13题

**考点说明：** 不等式的基本性质：根据负数的顺序，比较平方、倒数与商的大小。

来源：2026届上海高三一模金山卷，第13题。

规范化源文件：`2026届金山一模数学试卷 逐题解析.md`。

已知 $a < b < 0$ ，则下列不等式成立的是（）

- A. $a^2 < b^2$
- B. $\frac{1}{a} < \frac{1}{b}$
- C. $ab < b^2$
- D. $\frac{b}{a} < 1$

【答案】D

【解析】

【分析】利用不等式的性质，结合作差比较法逐一判断各选项即可.

【详解】对于 A，因 a < b < 0，由 $a^{2} - b^{2} = (a + b)(a - b) > 0$ ，可得 $a^{2} > b^{2}$ ，故 A 错误；对于 B，因 a < b < 0，则 ab > 0，利用不等式的性质，可得 $\frac{1}{b} < \frac{1}{a}$ ，即 $\frac{1}{a} > \frac{1}{b}$ ，故 B 错误；对于 C，因 a < b < 0，由 $ab - b^{2} = b(a - b) > 0$ ，可得 $ab > b^{2}$ ，故 C 错误；对于 D，因 a < b < 0，利用不等式的性质，可得 $1 > \frac{b}{a}$ ，即 $\frac{b}{a} < 1$ ，故 D 正确。故选：D.

## 2 绝对值不等式与等号条件

<a id="2026一模-奉贤-02"></a>
### 奉贤 · 原卷第2题

**考点说明：** 绝对值不等式：将绝对值小于常数转化为双边不等式，再解线性不等式。

来源：2026届上海高三一模奉贤卷，第2题。

规范化源文件：`2026届奉贤一模数学试卷 逐题解析.md`。

不等式 $|2x-1|<3$ 的解集是 \_\_\_\_.

【答案】 $(-1,2)$

【解析】

【分析】根据绝对值不等式计算求解.

【详解】因为 $\left|2x-1\right|<3$ ，所以-3<2x-1<3，所以-1<x<2，

所以不等式 $\left|2x-1\right|<3$ 的解集是 $(-1,2)$ .

故答案为： $(-1,2)$ .

<a id="2026一模-宝山-06"></a>
### 宝山 · 原卷第6题

**考点说明：** 绝对值方程与数轴距离：把两项绝对值看作点到两个定点的距离之和。

来源：2026届上海高三一模宝山卷，第6题。

规范化源文件：`2026届宝山一模数学试卷 逐题解析.md`。

关于 x 的方程 $\left|x-1\right|+\left|2-x\right|=1$ 的解集为 \_\_\_\_.

【答案】[1,2]

【解析】

【分析】根据绝对值三角不等式进行求解即可.

【详解】因为 $|x-1|+|2-x|\geq|x-1+2-x|$ ,

所以 $|x-1|+|2-x|\geq1$ ，

当且仅当 $(x - 1)(2 - x)\geq 0$ 时取等号，

即当 $1 \leq x \leq 2$ 时， $|x - 1| + |2 - x| = 1$ 成立，

所以关于 $x$ 的方程 $\left|x - 1\right| + \left|2 - x\right| = 1$ 的解集为[1,2]，

故答案为：[1,2]

## 3 分式不等式的同号转化与解集

<a id="2026一模-崇明-03"></a>
### 崇明 · 原卷第3题

**考点说明：** 分式不等式：以分子零点与分母零点为界划分区间，结合符号与定义域确定解集。

来源：2026届上海高三一模崇明卷，第3题。

规范化源文件：`2026届崇明一模数学试卷 逐题解析.md`。

不等式 $\frac{x - 2}{x + 1} < 0$ 的解集为 \_\_\_\_.

【答案】 $(-1,2)$

【解析】

【分析】

根据分式不等式的解法得 $(x-2)(x+1)<0$ ，再解二次不等式即可得答案.

【详解】解：由分式不等式的解法得原不等式 $\frac{x - 2}{x + 1} < 0$ 等价于 $(x - 2)(x + 1) < 0$

解不等式 $(x - 2)(x + 1) < 0$ 得 $-1 < x < 2$

故不等式 $\frac{x - 2}{x + 1} < 0$ 的解集为 $(-1,2)$ .

故答案为： $(-1,2)$

## 4 基本不等式：配凑、乘积与倒数和最值

<a id="2026一模-普陀-04"></a>
### 普陀 · 原卷第4题

**考点说明：** 基本不等式求最值：先平移变量得到正数，配凑乘积并核对取等条件。

来源：2026届上海高三一模普陀卷，第4题。

规范化源文件：`2026届普陀一模数学试卷 逐题解析.md`。

若 x > 1，则 $x + \frac{4}{x - 1}$ 的最小值是 \_\_\_\_.

【答案】5

【解析】

【分析】 $x+\frac{4}{x-1}=x-1+\frac{4}{x-1}+1$ ，利用基本不等式可得最值.

【详解】∵x>1，

$$
\therefore x + \frac {4}{x - 1} = x - 1 + \frac {4}{x - 1} + 1 \geq 2 \sqrt {(x - 1) \times \frac {4}{x - 1}} + 1 = 5,
$$

当且仅当 $x - 1 = \frac{4}{x - 1}$ 即 $x = 3$ 时取等号，

∴当 x=3 时， $x+\frac{4}{x-1}$ 取得最小值 5.

故答案为：5.

<a id="2026一模-浦东-05"></a>
### 浦东 · 原卷第5题

**考点说明：** 基本不等式求最值：根据正数与线性约束配凑乘积上界，并核对等号成立条件。

来源：2026届上海高三一模浦东卷，第5题。

规范化源文件：`2026届浦东一模数学试卷 逐题解析.md`。

已知正数 $a, b$ 满足 $a + 2b = 2$ ，则 $ab$ 的最大值为 \_\_\_\_.

【答案】 $\frac{1}{2}$

【解析】

【分析】直接利用基本不等式求解即可.

【详解】因为正数 a, b 满足 $a + 2b = 2$ ，所以 $2 = a + 2b \geq 2\sqrt{a \times 2b}$ ，平方化简得 $ab \leq \frac{1}{2}$ ，当且仅当 a = 2b = 1 时，等号成立，所以 ab 的最大值为 $\frac{1}{2}$ .

故答案为： $\frac{1}{2}$

排版说明：答案栏的重复等价表示已合并，数值未变。

<a id="2026一模-黄浦-08"></a>
### 黄浦 · 原卷第8题

**考点说明：** 基本不等式与最值：利用倒数约束构造乘积关系，注意等号成立条件。

来源：2026届上海高三一模黄浦卷，第8题。

规范化源文件：`2026届黄浦一模数学试卷 逐题解析.md`。

若正数 $m, n$ 满足 $\frac{4}{m} + \frac{9}{n} = 1$ ，则 $mn$ 的最小值为 \_\_\_\_.

【答案】144

【解析】

【分析】根据均值不等式求解.

【详解】因为 m, n 是正数，所以 $\frac{4}{m} + \frac{9}{n} \geq 2\sqrt{\frac{4}{m} \cdot \frac{9}{n}} = \frac{12}{\sqrt{mn}}$ ,

又 $\frac{4}{m} +\frac{9}{n} = 1$ ，所以 $\frac{12}{\sqrt{mn}}\leq 1$ ，即 $\sqrt{mn}\geq 12$

所以 $mn \geq 144$ ，当且仅当 $\frac{4}{m} = \frac{9}{n}$ ，即 $m = 8, n = 18$ 时， $mn$ 取得最小值144；

故答案为：144

<a id="2026一模-宝山-08"></a>
### 宝山 · 原卷第8题

**考点说明：** 直线斜率与基本不等式：由倾斜角得到正数变量的线性约束，求倒数和最小值并核对取等。

来源：2026届上海高三一模宝山卷，第8题。

规范化源文件：`2026届宝山一模数学试卷 逐题解析.md`。

已知第一象限的点 $(m, n)$ 和 $(6, 2)$ 经过直线 $l$ ，若直线 $l$ 的倾斜角为 $135^{\circ}$ ，则 $\frac{1}{m} + \frac{4}{n}$ 的最小值为 \_\_\_\_.

【答案】 $\frac{9}{8}$

【解析】

【分析】由题设知 $\frac{n - 2}{m - 6} = \tan 135^{\circ}$ ，根据目标式，结合基本不等式“1”的代换求最小值即可.

【详解】由题设知 $\frac{n - 2}{m - 6} = \tan 135^{\circ} = -1$ ，可得 $m + n = 8 (m, n > 0)$

$$
\therefore \frac {1}{m} + \frac {4}{n} = \frac {1}{8} \left(\frac {1}{m} + \frac {4}{n}\right) (m + n) = \frac {1}{8} \left(5 + \frac {n}{m} + \frac {4 m}{n}\right) \geq \frac {1}{8} \left(5 + 2 \sqrt {\frac {n}{m} \cdot \frac {4 m}{n}}\right) = \frac {9}{8},
$$

当且仅当 $n = 2m$ 时，即 $m = \frac{8}{3}, n = \frac{16}{3}$ 时，等号成立， $\frac{1}{m} + \frac{4}{n}$ 的最小值为 $\frac{9}{8}$ .

故答案为： $\frac{9}{8}$ .

排版说明：答案栏的重复等价表示已合并，数值未变。

<a id="2026一模-金山-09"></a>
### 金山 · 原卷第9题

**考点说明：** 等差中项与整数最值：由非零公差得到下标约束，再在允许的正整数情形中求最小值。

来源：2026届上海高三一模金山卷，第9题。

规范化源文件：`2026届金山一模数学试卷 逐题解析.md`。

在公差不为 0 的等差数列 $\{a_{n}\}$ 中，若 $a_{3}$ 是 $a_{x}$ 与 $a_{y}$ 的等差中项，则 $\frac{1}{x} + \frac{4}{y}$ 的最小值为 \_\_\_\_.

【答案】 $\frac{3}{2}$

【解析】

【分析】根据等差中项性质可得 $x + y = 6$ ，再利用基本不等式中“1”的应用计算可得结果.

【详解】因为在公差不为0的等差数列 $\{a_{n}\}$ 中， $a_3$ 是 $a_{x}$ 与 $a_{y}$ 的等差中项，

所以 $2a_{3}=a_{x}+a_{y}$ ，所以 $x+y=6$ ，

因此 $\frac{1}{x} +\frac{4}{y} = \frac{1}{6}\big(x + y\big)\left(\frac{1}{x} +\frac{4}{y}\right) = \frac{1}{6}\left(5 + \frac{y}{x} +\frac{4x}{y}\right)\geq \frac{1}{6}\left(5 + 2\sqrt{\frac{y}{x}\cdot\frac{4x}{y}}\right) = \frac{3}{2},$

当且仅当 $\frac{y}{x} = \frac{4x}{y}$ ，即 $x = 2, y = 4$ 时等号成立，

所以 $\frac{1}{x} +\frac{4}{y}$ 的最小值为 $\frac{3}{2}$

故答案为: $\frac{3}{2}$

<a id="2026一模-长宁-09"></a>
### 长宁 · 原卷第9题

**考点说明：** 基本不等式与取等条件：利用正数约束消去变量或配凑和，连续估计并检查等号能否同时成立。

来源：2026届上海高三一模长宁卷，第9题。

规范化源文件：`2026届长宁一模数学试卷 逐题解析.md`。

已知 $a, b, c$ 均为正实数，且 $a(b + c) = 1$ ，则 $\frac{1}{a} + \frac{1}{b + c} + \frac{4}{a + b + c}$ 的最小值为 \_\_\_\_.

【答案】4

【解析】

【分析】由 $a(b + c) = 1$ 可得 $b + c = \frac{1}{a}$ ，所以原式可化为 $\frac{1}{a} + a + \frac{4}{a + \frac{1}{a}}$ ①，令 $t = a + \frac{1}{a}$ ，利用基本不等式求出 $t$ 的范围，则①式可化为 $y = t + \frac{4}{t}$ ，再次利用基本不等式求出 $y$ 的范围即可得解。（注意两次应用基本不等式，等号成立的条件必须相同）

【详解】由 $a(b+c)=1$ 可得 $b+c=\frac{1}{a}$ ，所以原式 $=\frac{1}{a}+a+\frac{4}{a+\frac{1}{a}}$ ①.

令 $t = a + \frac{1}{a}$ ，当 $a > 0$ 时， $a + \frac{1}{a}\geq 2\sqrt{a\times\frac{1}{a}} = 2$

当且仅当 $a = \frac{1}{a}$ ，即 $a = 1$ 时等号成立，所以 $t\geq 2$

所以①式可化为原式 $= t + \frac{4}{t}$

令 $y = t + \frac{4}{t}$ ，则 $t + \frac{4}{t} \geq 2\sqrt{t \times \frac{4}{t}} = 4$ ，

当且仅当 $t = \frac{4}{t}$ ，即 $t = 2$ ，即 $a = 1$ 时等号成立，所以 $y \geq 4$

所以 $\frac{1}{a} +\frac{1}{b + c} +\frac{4}{a + b + c}$ 的最小值为4.

故答案为：4

### 奉贤 · 原卷第10题

**考点说明：** 约束二次最值：利用线性关系消元，在非负变量对应的区间上求二次函数最小值。

来源：2026届上海高三一模奉贤卷，第10题。

规范化源文件：`2026届奉贤一模数学试卷 逐题解析.md`。

已知两个非负实数 $a$ 、 $b$ 满足 $a + 2b = 2$ ，则 $(a - 1)^2 + (b - 4)^2$ 的最小值是

【答案】10

【解析】

【分析】由 a=2-2b，代入结合二次函数单调性即可求解.

【详解】因为两个非负实数 $a$ 、 $b$ ， $a + 2b = 2$ ，

所以 $a = 2 - 2b \geq 0$ ， $0 \leq b \leq 1$

所以 $(a - 1)^2 + (b - 4)^2 = (1 - 2b)^2 + (b - 4)^2 = 5b^2 - 12b + 17$

令 $y=5b^{2}-12b+17$ ，对称轴为 $b=\frac{6}{5}$ ，

由二次函数单调性可知当 b=1 时，取得最小值 10，

故答案为：10

<a id="2026一模-徐汇-10"></a>
### 徐汇 · 原卷第10题

**考点说明：** 分段函数同值多根与最值：利用图像和共同函数值联系三根，确定参数范围，再优化所给表达式。

来源：2026届上海高三一模徐汇卷，第10题。

规范化源文件：`2026届徐汇一模数学试卷 逐题解析.md`。

设 $f(x) = \begin{cases} |x - 2|, & x \geq 0 \\ -\frac{1}{x}, & x < 0 \end{cases}$ ，若实数 $x_1, x_2, x_3$ 满足 $x_1 < x_2 < x_3$ ，且 $f(x_1) = f(x_2) = f(x_3)$ ，则 $\frac{\sqrt{x_2x_3}}{x_1}$ 的最小值为 \_\_\_\_.

【答案】-2

【解析】

【分析】根据题目条件，令 $f(x_{1}) = f(x_{2}) = f(x_{3}) = k(k > 0)$ ，用 $k$ 替换 $x_{1}, x_{2}, x_{3}$ ，构造函数结合基本不等式求值.

【详解】已知分段函数 $f(x) = \begin{cases} |x - 2|, & x \geq 0 \\ -\frac{1}{x}, & x < 0 \end{cases}$ ，且实数 $x_{1}, x_{2}, x_{3}$ 满足 $x_{1} < x_{2} < x_{3}$ ，

令 $f(x_{1})=f(x_{2})=f(x_{3})=k(k>0)$ ,

对于 $x_{1} < 0$ ，由 $f(x_{1}) = -\frac{1}{x_{1}} = k$ ， $x_{1} = -\frac{1}{k}$

对于 $x \geq 0, f(x) = |x - 2| = k, \quad x = 2 \pm k,$

因 $x_{2}<x_{3}$ ，故 $x_{2}=2-k, x_{3}=2+k$ ， $k\leq2$ ，否则 $x_{2}=2-k<0$ 不满足 $x\geq0$ ，

$$
x _ {2} x _ {3} = (2 - k) (2 + k) = 4 - k ^ {2} \Rightarrow \sqrt {x _ {2} x _ {3}} = \sqrt {4 - k ^ {2}}
$$

故 $\frac{\sqrt{x_2x_3}}{x_1} = \frac{\sqrt{4 - k^2}}{-\frac{1}{k}} = -k\sqrt{4 - k^2}$

设 $g(k) = -k\sqrt{4 - k^{2}} (0 < k \leq 2)$ ，令 $g(k) = -h(k)$ ，等价于求 $h(k) = k\sqrt{4 - k^{2}}$ 的最大值， $h(k)=\sqrt{k^{2}\left(4-k^{2}\right)}\leq\sqrt{\left(\frac{k^{2}+4-k^{2}}{2}\right)^{2}}=2$ ，当且仅当 $k^{2}=4-k^{2}$ 即 $k=\sqrt{2}$ 时取等号，
此时 $h(k)_{\max}=2$ ，故 $g(k)_{\min}=-2$ ，

综上， $\frac{\sqrt{x_{2}x_{3}}}{x_{1}}$ 的最小值为 -2.

故答案为：-2

核对说明：依据徐汇同题解析版PDF第4—5页，保留本题函数解析，已去除第二个答案标签起混入的第11题几何解析。

<a id="2026一模-松江-11"></a>
### 松江 · 原卷第11题

**考点说明：** 圆的切线与几何最值：由圆与矩形边、对角线的切线关系建立约束，转化为矩形面积最小值。

来源：2026届上海高三一模松江卷，第11题。

规范化源文件：`2026届松江一模数学试卷 逐题解析.md`。

某社区为扩大居民的活动区域, 计划将社区内原有的半径为 $10 \mathrm{~m}$ 的圆形花坛扩建成一个矩形花园. 若要求扩建前的圆与扩建后矩形的两邻边和一条对角线都相切, 则矩形花园占地面积的最小值为 \_\_\_\_. (结果精确到 $1 \mathrm{~m}^{2}$ )

【答案】 $1166\mathrm{m}^2$

【解析】

【分析】设 AB = a m，AD = b m，可得圆 O 的半径 $r = \frac{ab}{a + b + \sqrt{a^{2} + b^{2}}} = 10 \, m$ ，利用基本不等式运算求解即可.

【详解】如图，在矩形 ABCD 中，设 AB = a m，AD = b m，a > 0, b > 0，

![](images/2026一模-松江-11-2026-yimo-songjiang-fig-01.jpg)

则 $BD = \sqrt{a^2 + b^2}\mathrm{m}$ ，圆 $O$ 的半径 $r = \frac{ab}{a + b + \sqrt{a^2 + b^2}} = 10\mathrm{m}$ ，

因为 $a + b \geq 2\sqrt{ab}$ ， $a^2 + b^2 \geq 2ab$ ，即 $\sqrt{a^2 + b^2} \geq \sqrt{2ab}$ ，

当且仅当 $a = b = 10\left(2 + \sqrt{2}\right)$ 时，等号成立，

可得 $\frac{ab}{a + b + \sqrt{a^2 + b^2}}\leq \frac{ab}{2\sqrt{ab} + \sqrt{2ab}} = \frac{\sqrt{ab}}{2 + \sqrt{2}},$

即 $10 \leq \frac{\sqrt{ab}}{2 + \sqrt{2}}$ ，解得 $ab \geq 200(3 + 2\sqrt{2}) \approx 1166$ ，

所以矩形花园占地面积的最小值为 $1166m^{2}$ .

故答案为： $1166m^{2}$
