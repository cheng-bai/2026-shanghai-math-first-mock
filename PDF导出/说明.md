# 全站 PDF 导出

本站已发布的整卷、专题、历史解析和多年度汇编阅读页使用同一套 A4 排版。下载直接保存对应版本的 PDF，打印调用浏览器对话框。两者输出当前页面完整题集，不受搜索、跳题和解析折叠状态影响。打印时建议关闭浏览器自带的「页眉和页脚」。

导出保留题干、公式、插图和必要的待核提示，隐藏来源和网页操作。教师版保留现有答案、解析和红色考点标签；学生版保留作答区。网站另行提供的原始扫描件不使用此模板。

在能加载 `playwright` 且已安装 Chromium 的 Node.js 环境中，从网站根目录运行：

```sh
node PDF导出/构建.cjs
node PDF导出/构建.cjs '整卷/06-' 'page-14.html'
node PDF导出/构建.cjs --check
```

三条命令分别用于全站生成、按网页路径匹配增量生成和只检查导出内容。可用 `CHROMIUM_EXECUTABLE` 指定浏览器，通过 `PDF_BUILD_REPORT` 保存 JSON 检查报告。

更改页面内容、图片或模板后重新生成受影响的 PDF。发布时须同时包含对应网页、共享资源和生成的文件：FY27 整卷在 `FY27分类汇编/整卷/PDF/`，其他阅读页在 `PDF导出/文件/`。现有原始 PDF 的 Release 下载方式不变。
