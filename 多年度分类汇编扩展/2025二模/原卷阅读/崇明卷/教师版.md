事件A∩B表示“n次中既有正面朝上又有反面朝上且至多有一次正面朝上”，即“n次中有一次正面朝上”，有 $\mathrm { C } _ { n } ^ { 1 } = n$ 种情况，所以 $P \left( A \cap B \right) = { \frac { n } { 2 ^ { n } } }$
