### 奉贤 · 第4题

设 $f(x)=\begin{cases}\ln x+1,&x>0,\\2^x+1,&x\leq 0.\end{cases}$ 若 $f(x_0)=1$，则 $x_0=$______。

> 本题资料或解析有待核事项，预览不可作为已审定成品。

**考点：** 分段指数对数函数的给值求自变量

**难度依据：** 须分别检查两段方程与区间

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。；题干分段函数缺少x>0时ln x+1这一整支；已定向下载同名PDF，第1页文字层确认两支为ln x+1(x>0)、2^x+1(x≤0)，本分类未改底稿。

【答案】$1$

【解析】

根据分段函数，分 $x_0>0$ 和 $x_0\le0$ 求解即可。

当 $x_0>0$ 时，$f(x_0)=\ln x_0+1=1$，解得 $x_0=1$，满足条件；

当 $x_0\le0$ 时，$f(x_0)=2^{x_0}+1=1$，方程无解。

所以 $x_0=1$。

故答案为：$1$。

### 奉贤 · 第5题

若 $A,B,C,D,E$ 五人站成一排，如果 $A,B$ 必须相邻，那么排法共 $\underline{\qquad}$ 种。

**考点：** 相邻排列的捆绑法

**难度依据：** 整体排列后补内部排列

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】$48$。

【解析】

元素相邻问题运用捆绑法求解。

第一步：把 $A,B$ 捆绑当作一个元素，与 $C,D,E$ 进行排列，共有 $\mathrm A_4^4$ 种；

第二步：$A,B$ 之间进行排列，共有 $\mathrm A_2^2$ 种；

根据分步计数原理可知，排法的总数共有 $\mathrm A_4^4\mathrm A_2^2=48$ 种。

故答案为：$48$。

### 奉贤 · 第6题

$\left(x^6+\frac{1}{x\sqrt{x}}\right)^5$ 的二项展开式中的常数项为 $\underline{\qquad}$。（用数字作答）

**考点：** 含分数指数的二项展开常数项

**难度依据：** 准确列指数并令其为零

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】$5$。

【解析】

写出展开式的通项，令 $x$ 的指数为 $0$ 即可。

由题意可知：

$$
T_{r+1}=\mathrm C_5^r x^{30-6r}\left(\frac{1}{x\sqrt{x}}\right)^r=\mathrm C_5^r x^{30-6r}x^{-\frac32r}=\mathrm C_5^r x^{30-\frac{15}{2}r}.
$$

令 $30-\frac{15}{2}r=0$，得 $r=4$，所以常数项为 $\mathrm C_5^4=5$。

故答案为：$5$。

### 奉贤 · 第7题

已知抛物线 $x^2=ay\left(a>0\right)$ 上有一点 $P$ 到准线的距离为 $6$，点 $P$ 到 $x$ 轴的距离为 $4$，则抛物线的焦点坐标为 $\underline{\qquad}$。

**考点：** 抛物线准线距离与焦点参数

**难度依据：** 先定纵坐标再用准线距离反求参数

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】$(0,2)$。

【解析】

根据题意求出点 $P$ 的纵坐标，结合点 $P$ 到准线的距离可求出 $a$ 的值，即可得出抛物线焦点的坐标。

抛物线 $x^2=ay\left(a>0\right)$ 的准线方程为 $y=-\frac a4$。

设点 $P(x,y)$，则 $y\geq0$，由于点 $P$ 到准线的距离为 $y+\frac a4=6$，可得 $y=6-\frac a4$。

因为点 $P$ 到 $x$ 轴的距离为 $4$，则 $y=4$，所以 $6-\frac a4=4$，解得 $a=8$。

故抛物线的方程为 $x^2=8y$，其焦点坐标为 $(0,2)$。

故答案为：$(0,2)$。

### 奉贤 · 第8题

在复平面内，$O$ 为坐标原点，复数 $z_1=\mathrm i(-4-3\mathrm i)$，$z_2=12+5\mathrm i$ 对应的点分别为 $Z_1,Z_2$，其中 $\mathrm i$ 为虚数单位，则 $\langle\overrightarrow{OZ_1},\overrightarrow{OZ_2}\rangle$ 的大小为 ______。

> 本题资料或解析有待核事项，预览不可作为已审定成品。

**考点：** 复数运算与复平面坐标；坐标数量积求向量夹角

**难度依据：** 复数乘法转坐标后求余弦与夹角

**核查说明：** 仅核本题所列字段及页面；不等于全卷终审。；题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。；题干夹角括号缺失，需规范向量夹角符号。

【解析】

由复数乘法运算求得 $z_1$，进而得到 $\overrightarrow{OZ_1},\overrightarrow{OZ_2}$，利用向量数量积运算和模长公式求得 $\cos\langle\overrightarrow{OZ_1},\overrightarrow{OZ_2}\rangle$，进而得到 $\langle\overrightarrow{OZ_1},\overrightarrow{OZ_2}\rangle$。

因为 $z_1=\mathrm i(-4-3\mathrm i)=3-4\mathrm i$，$z_2=12+5\mathrm i$，

所以 $\overrightarrow{OZ_1}=(3,-4)$，$\overrightarrow{OZ_2}=(12,5)$，

$$
\cos\left\langle\overrightarrow{OZ_1},\overrightarrow{OZ_2}\right\rangle=\frac{\overrightarrow{OZ_1}\cdot\overrightarrow{OZ_2}}{\left|\overrightarrow{OZ_1}\right|\left|\overrightarrow{OZ_2}\right|}=\frac{3\times12-20}{\sqrt{3^2+(-4)^2}\times\sqrt{12^2+5^2}}=\frac{16}{65},
$$

所以 $\langle\overrightarrow{OZ_1},\overrightarrow{OZ_2}\rangle=\arccos\frac{16}{65}$。

### 奉贤 · 第9题

甲乙两人下棋，每局两人获胜的可能性一样，某一天两人要进行一场三局两胜的比赛，最终胜者赢得100元奖金，第一局比赛甲获胜，后因为有其他事情而中止比赛，则甲应该分 $\underline{\qquad}$ 元奖金才公平？

**考点：** 中止赛制的条件胜率和公平分奖

**难度依据：** 当前比分下用乙再连胜的补事件

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】$75$。

【解析】

分别求出甲、乙最终获胜的概率，即可求出答案。

乙最后获胜的情况为第二局、第三局必须乙胜，其概率为 $\frac12\times\frac12=\frac14$。

即甲最终获胜的概率为 $\frac34$，乙最终获胜的概率为 $\frac14$。

故甲的奖金为 $100\times\frac34=75$ 元。

故答案为：$75$。

### 奉贤 · 第12题

已知集合 $M=\{P_0,P_1,P_2,\cdots,P_n\}$，$n\geq2$，$n\in\mathbb N$，是由函数 $y=\cos x$，$x\in[0,2\pi]$ 的图象上两两不相同的点构成的点集，集合 $S=\{a\mid a=\overrightarrow{OP_0}\cdot\overrightarrow{OP_i},\ i=0,1,2,\cdots,n,\ n\geq2,\ n\in\mathbb N\}$，其中 $P_0(0,1)$、$P_1(\pi,-1)$。若集合 $S$ 中的元素按照从小到大的顺序排列能构成公差为 $d$ 的等差数列，当 $d\in\left\{\frac12,1\right\}$ 时，则符合条件的点集 $M$ 的个数为________。

> 本题资料或解析有待核事项，预览不可作为已审定成品。

**考点：** 坐标数量积提取纵坐标；有限等差数列公差分类；余弦函数定值点枚举；有必选点约束的集合计数；点集到数集映射的重合与去重

**难度依据：** 公差两种情形下按同纵坐标点的非空选择计数

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。；原解多个余弦值与横坐标被错排，计数思路可辨但公式未校净。

【答案】$60$。

【校订说明】以下解析依据题设重新整理，非来源解析逐字转录。

【解析】设 $P_i=(x_i,y_i)$，则 $\overrightarrow{OP_0}\cdot\overrightarrow{OP_i}=y_i=\cos x_i$。因此 $S\subseteq[-1,1]$，且 $-1,1\in S$。

当 $d=1$ 时，$S=\{-1,0,1\}$。纵坐标为 $0$ 的点有两个，须至少选一个，有 $3$ 种选法；除已选的 $P_0$ 外，纵坐标为 $1$ 的点 $(2\pi,1)$ 可选可不选，有 $2$ 种选法；纵坐标为 $-1$ 的点只有已选的 $P_1$。故有 $2\times3=6$ 个点集。

当 $d=\frac12$ 时，$S=\left\{-1,-\frac12,0,\frac12,1\right\}$。纵坐标为 $-\frac12$、$0$、$\frac12$ 的点各有两个，每组均须至少选一个，各有 $3$ 种选法；点 $(2\pi,1)$ 可选可不选。故有 $2\times3^3=54$ 个点集。

两种情形互不重合，故所求为 $6+54=60$。

### 奉贤 · 第13题

在 $\triangle ABC$ 中，“$C=\frac{\pi}{2}$”是“$\sin^2A+\sin^2B=1$”的（　）

A. 充分不必要条件

B. 必要不充分条件

C. 充要条件

D. 既不充分也不必要条件

**考点：** 三角命题的充分必要性与反例；三角形内角关系及平方和恒等式

**难度依据：** 充分性用互余关系必要性需构造非直角反例

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】A

【解析】

结合同角三角函数关系、诱导公式，分别从充分性、必要性两方面来说明即可。

一方面：

$$
C=\frac{\pi}{2}\Rightarrow A+B=\frac{\pi}{2}\Rightarrow\sin A=\sin\left(\frac{\pi}{2}-B\right)=\cos B,
$$

所以 $\sin^2A+\sin^2B=\cos^2B+\sin^2B=1$。

另一方面，当 $A=\frac{2\pi}{3}$，$B=C=\frac{\pi}{6}$ 时，$\sin^2A+\sin^2B=\left(\frac{\sqrt3}{2}\right)^2+\left(\frac12\right)^2=1$，但 $C\ne\frac{\pi}{2}$。

所以“$C=\frac{\pi}{2}$”是“$\sin^2A+\sin^2B=1$”的充分不必要条件。

故选：A。

### 奉贤 · 第14题

函数 $y = \log _ { 2 } \sin x + \log _ { 2 } \cos x$ ，则下列命题正确的是（ ）

A. 函数是偶函数

B. 函数定义域是 $\left( 0 , { \frac { \pi } { 2 } } \right)$

C. 函数最大值−1

D. 函数的最小正周期为π

**考点：** 复合对数函数定义域与周期；正弦余弦同正区域及二倍角最值

**难度依据：** 周期不能只看化简式还需保留原定义域

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】C

【解析】

求出函数f(x)的定义域，可判断AB选项；利用二倍角的正弦公式以及正弦函数的有界性可判断C选项；利用正弦型函数的周期性可判断D选项.

设 $f \left( x \right) = \log _ { 2 } \sin x + \log _ { 2 } \cos x$ ，由 $\left\{ { \begin{array} { l } { \sin x > 0 } \\ { \cos x > 0 } \end{array} } \right.$ 可得 $2 k \pi < x < 2 k \pi + { \frac { \pi } { 2 } } ( k \in { \bf Z } )$

所以，函数f(x)的定义域为 $\left\{ x \Big \vert 2 k \pi < x < 2 k \pi + \frac { \pi } { 2 } , k \in \mathbf { Z } \right\}$ ，定义域不关于原点对称

所以，函数f(x)不是偶函数，A错B错；

当 $2 k \pi < x < 2 k \pi + \frac { \pi } { 2 } ( k \in { \bf Z } )$ 时，则 $4 k \pi < 2 x < 4 k \pi + \pi \left( k \in \mathbf { Z } \right)$

$$
f (x) = \log_ {2} (\sin x \cos x) = \log_ {2} \left(\frac {1}{2} \sin 2 x\right) \leq \log_ {2} \frac {1}{2} = - 1,
$$

当且仅当 $2 x = \frac { \pi } { 2 } + 4 k \pi \left( k \in \mathbf { Z } \right)$ 时，即当 $x = { \frac { \pi } { 4 } } + 2 k \pi \left( k \in { \mathbf { Z } } \right)$ 时，函数f(x)取最大值−1，C对；

因为 $f \left( 2 \pi + x \right) = \log _ { 2 } \sin \left( 2 \pi + x \right) + \log _ { 2 } \cos \left( 2 \pi + x \right) = \log _ { 2 } \sin x + \log _ { 2 } \cos x = f \left( x \right)$

结合函数f(x)的定义域可知，函数f(x)的最小正周期为2π，D错.故选：C.

### 奉贤 · 第15题

在四棱锥 $S - A B C D$ 中，若 $\overrightarrow { S A } = x \overrightarrow { S B } + y \overrightarrow { S C } + z \overrightarrow { S D }$ ，则实数组(x, y, z)可能是（ ）

A. $( 1 , - 1 , 1 )$

B. $( 1 , 0 , - 1 )$

A. ①与②均为真命题

B. ①与②均为假命题

【答案】C

【解析】

对于①，取 $a_n=3n-2$，各项均为正整数，公差为 $3$。当 $n=2$ 时，$S_2=5$，对任意正整数 $m$，

$$|S_2-a_m|=|7-3m|\geq 1=a_1.$$

因此该数列不可控，①为假命题。

对于②，由各项为正且不是常数列，知 $q>0$ 且 $q\ne1$。令 $T_n=\frac{S_n}{a_1}=\frac{q^n-1}{q-1}$，可控条件为：对每个正整数 $n$，存在正整数 $m_n$，使得

$$|T_n-q^{m_n-1}|<1.$$

若 $q>1$，两边除以 $q^n$ 并令 $n\to\infty$，得

$$q^{m_n-n-1}\longrightarrow\frac1{q-1}.$$

由于 $q$ 的整数次幂在任一正的有界闭区间内只有有限个，故指数 $m_n-n-1$ 最终固定为某个整数 $k$，且 $q^k=\frac1{q-1}$。于是对充分大的 $n$，

$$|T_n-q^{m_n-1}|=\frac1{q-1}<1,$$

从而 $q>2$。但此时 $\frac1q<\frac1{q-1}<1$，区间 $(\frac1q,1)$ 中没有 $q$ 的整数次幂，矛盾。所以 $q>1$ 不可能。

若 $0<q<1$，则 $T_n\geq1$，且对任意正整数 $m$ 有 $q^{m-1}\leq1$。因此可控当且仅当每个 $n$ 都满足 $T_n<2$：必要性由 $T_n-q^{m-1}<1$ 得到，充分性取 $m=1$ 即可。又 $T_n=\frac{1-q^n}{1-q}$ 严格递增，极限为 $\frac1{1-q}$，且每一项都小于该极限，故上述条件等价于 $\frac1{1-q}\leq2$，即 $0<q\leq\frac12$。特别地，$q=\frac12$ 时每个有限的 $n$ 均有 $T_n<2$。

故②为真命题，选 C。
