### 普陀 · 第2题

已知某抛物线的准线方程为y＝1，则该抛物线的标准方程为

**考点：** 准线方程反求抛物线标准式

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】$x ^ { 2 } = - 4 y$

【解析】

设出抛物线的标准方程后，根据准线方程可解得结果.依题意可设抛物线的标准方程为：

$$

所以该抛物线的标准方程为： $x ^ { 2 } = - 4 y$

故答案为： $x ^ { 2 } = - 4 y$

设i为虚数单位，若复数z满足 $z \cdot { \overline { { z } } } + z - { \overline { { z } } } = 4 + 2 \mathrm { i }$ ，则|z| = .

### 普陀 · 第6题

设 $\triangle ABC$ 的内角 $A,B,C$ 的对边分别为 $a,b,c$，若 $b=4$，$\sin\left(A+\frac{\pi}{3}\right)=0$，$\triangle ABC$ 的面积为 $\sqrt{3}$，则 $a$ 的值为 $\underline{\qquad}$。

【解析】

由已知得A的大小，再根据 $\triangle A B C$ 的面积公式得c的值，从而由余弦定理可得a的值.

$$
\because A \in (0, \pi), \therefore A + \frac {\pi}{3} \in \left(\frac {\pi}{3}, \frac {4 \pi}{3}\right),
$$

又 $\sin \left( A + { \frac { \pi } { 3 } } \right) = 0 .$ ，所以 $A + { \frac { \pi } { 3 } } = \pi$ ，故 $A = \frac { 2 \pi } { 3 }$ ，则 $\triangle A B C$ 的面积 $S _ { \triangle A B C } = \frac { 1 } { 2 } b c \sin A = \frac { 1 } { 2 } \times 4 \times c \sin \frac { 2 \pi } { 3 } = \sqrt { 3 }$ ，所以 $c = 1$， 由余弦定理得 $a ^ { 2 } = b ^ { 2 } + c ^ { 2 } - 2 b c \cos A = 1 6 + 1 - 2 \times 4 \times 1 \times \left( - { \frac { 1 } { 2 } } \right) = 2 1 ,$ 故 $a = \sqrt { 2 1 }$

故答案为： $\sqrt { 2 1 }$

### 普陀 · 第7题

设椭圆 $C:\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\ (a>b>0)$ 的左、右焦点分别为 $F_1$、$F_2$，左顶点为 $A$，若椭圆 $C$ 的离心率为 $\dfrac{1}{3}$，则 $\dfrac{|F_2A|}{|AF_1|}$ 的值为_______。

**考点：** 椭圆顶点焦点距离比与离心率

**难度依据：** 把线段长度写成a加减c

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】2。

### 普陀 · 第8题

若圆锥 $PO$ 的体积为 $\dfrac{2\sqrt{2}\pi}{3}$，它的母线与底面所成的角的余弦值为 $\dfrac{1}{3}$，则圆锥 $PO$ 的表面积为_______。

**考点：** 圆锥线面角体积与表面积；直角三角形中的余弦边比

**难度依据：** 先由夹角确定母线半径比例再用体积定尺度

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】$4\pi$。

【解析】

![](images/5ce7122d0ee33b83.jpg)

设圆锥底面半径为 $r$，母线长为 $l$。由母线与底面所成角的余弦值为 $\dfrac{1}{3}$，得 $\dfrac{r}{l}=\dfrac{1}{3}$，即 $l=3r$，故圆锥的高为 $\sqrt{l^2-r^2}=2\sqrt{2}r$。

由体积 $\dfrac{1}{3}\pi r^2\cdot 2\sqrt{2}r=\dfrac{2\sqrt{2}\pi}{3}$，得 $r=1$，$l=3$。因此圆锥的表面积为 $\pi rl+\pi r^2=4\pi$。

### 普陀 · 第10题

设平面上四点 $P$、$Q$、$M$、$N$ 满足：$|PM|=|PN|=4$，$|PQ|=2$，若 $\overrightarrow{QM}\cdot\overrightarrow{QN}=0$，则 $|MN|$ 的最小值为 $\underline{\qquad}$。

> 本题资料或解析有待核事项，预览不可作为已审定成品。

**考点：** 数量积零转直角圆周关系；双圆约束中的弦长最值

**难度依据：** 将垂直条件转圆再用距离约束确定最短弦

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。；原解将r²=8−2√7舍去却随后取其为最小值，又出现r>4的不可能分支；结论不能替代证明，须重核。

【答案】$2\sqrt7-2$。

【解析】设 $O$ 为 $MN$ 的中点。由 $\overrightarrow{QM}\cdot\overrightarrow{QN}=0$，得 $OQ=OM=ON$。令 $OM=OQ=r$，$OP=m$，由 $PM=PN=4$，得

$$r^2+m^2=16.$$

又 $PQ=2$，由三角形边长关系得 $|m-r|\le2$，从而

$$16-2mr=(m-r)^2\le4,\qquad mr\ge6.$$

于是 $(m+r)^2=16+2mr\ge28$，所以 $m+r\ge2\sqrt7$。结合 $m-r\le2$，得 $2r\ge2\sqrt7-2$。

当 $r=\sqrt7-1$，$m=\sqrt7+1$ 时，取 $Q$ 在线段 $OP$ 上，使 $OQ=r$，并取过 $O$ 且垂直于 $OP$ 的直径 $MN$，则 $PQ=2$，$PM=PN=4$，且 $\overrightarrow{QM}\cdot\overrightarrow{QN}=0$。因此最小值为 $2\sqrt7-2$。

【审校说明】本解析为独立重建。来源解析错误舍去了 $r^2=8-2\sqrt7$，并错误纳入 $r>4$；来源答案与上述结论一致。

### 普陀 · 第12题

设 $a>b>0$，函数 $y=f(x)$ 的表达式为 $f(x)=\left|x-\frac1x+\ln x\right|$，若 $f(a)=f(b)$，且关于 $x$ 的方程

$$|x^2+ax+2ab|+|x^2-ax+2ab|=2a|x|$$

的整数解有且仅有4个，则 $a$ 的取值范围是 $\underline{\qquad}$。

> 本题资料或解析有待核事项，预览不可作为已审定成品。

**考点：** 单调函数倒数反对称关系；绝对值三角不等式等号与整数解；函数约束联动整数解计数

**难度依据：** 先推出ab为一再将四个整数根转为两个正整数解

**核查说明：** 仅修复所列OCR公式及其定界符错位；原解数学疑点和其他可渲染错识未因此消除。；题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。

【答案】$\left[3,\frac{11}{3}\right)$。

【解析】令 $g(x)=x-\frac1x+\ln x$（$x>0$）。因为 $g'(x)=1+\frac1{x^2}+\frac1x>0$，所以 $g(x)$ 在 $(0,+\infty)$ 上严格递增。又 $g(1)=0$，且 $g(\frac1x)=-g(x)$。由 $a>b>0$ 及 $|g(a)|=|g(b)|$，可得 $0<b<1<a$，并有 $g(b)=-g(a)=g(\frac1a)$，因此 $b=\frac1a$。

![](images/613e41ac0146d5a2.jpg)

将 $ab=1$ 代入方程。由绝对值三角不等式的等号条件，原方程等价于

$$ (x^2+2)^2-a^2x^2\leq 0\quad\Longleftrightarrow\quad x^2+2\leq a|x|。$$

显然 $x=0$ 不满足条件，且整数解关于原点成对。对正整数 $n$，上述不等式等价于 $a\geq n+\frac2n$。当 $n=1,2$ 时，右端均为 $3$；当 $n\geq2$ 时，

$$\left(n+1+\frac2{n+1}\right)-\left(n+\frac2n\right)=1-\frac2{n(n+1)}>0。$$

因此，恰有两个正整数解当且仅当 $3\leq a<3+\frac23=\frac{11}{3}$。反之，在此范围内取 $b=\frac1a$，满足 $a>b>0$ 和 $f(a)=f(b)$，且整数解恰为 $\pm1,\pm2$。故所求范围为 $\left[3,\frac{11}{3}\right)$。

![](images/f01928e26e089643.jpg)

### 普陀 · 第13题

设 $\alpha\in\mathbb{R}$，则“$\cos 2\alpha=\frac{1}{3}$”是“$\sin\alpha=\frac{\sqrt{3}}{3}$”的（　）

A. 充分非必要条件

B. 必要非充分条件

C. 充要条件

D. 既非充分又非必要条件

> 本题资料或解析有待核事项，预览不可作为已审定成品。

**考点：** 二倍角命题的充分必要条件；二倍角公式与符号分支

**难度依据：** 平方关系不能确定正弦符号

**核查说明：** 题干与解析已用于人工归类，尚未完成整题公式校净与独立数学终审。；题干α范围大段乱码；同名PDF第9页文字层已确认“设α∈R”，本分类不改源稿。

【答案】B

【解析】

由 $\cos 2\alpha=1-2\sin^2\alpha$，可得 $\cos 2\alpha=\dfrac13$ 等价于 $\sin\alpha=\dfrac{\sqrt3}{3}$ 或 $\sin\alpha=-\dfrac{\sqrt3}{3}$。

因此，$\sin\alpha=\dfrac{\sqrt3}{3}$ 能推出 $\cos 2\alpha=\dfrac13$；反之，当 $\sin\alpha=-\dfrac{\sqrt3}{3}$ 时，前者成立而后者不成立。故“$\cos 2\alpha=\dfrac13$”是“$\sin\alpha=\dfrac{\sqrt3}{3}$”的必要非充分条件，选 B。
