(3) (6分)在32名女生身高的数据中，其中一个数据记录有误，错将165cm记录为156cm，由错误数据求得这32个数据的平均数为161cm，方差为23.6875，求原始数据的平均数及方差．（平均数结果保留精确值，方差结果精确到0.01）

**考点：** （1）样本比例估计人数；（2）组合计数求概率；（3）修正均值和方差

**难度依据：** 分层抽样、概率与方差修正；（1）样本比例估计人数；（2）组合计数求概率；（3）修正均值和方差

【解析】

(1) 根据题意可知，抽样比为5:1，所以该校高一学生中男生有34×5 = 170名，女生有 $3 2 \times 5 = 1 6 0$ 名；

(2) 从这66名学生中随机抽取两名共有 $\mathrm { \dot { C } _ { 6 6 } ^ { 2 } }$ 种，两名都是男生的抽法共有 $\mathrm { \dot { C } _ { 3 4 } ^ { 2 } }$ 种，所以这两名都是男生的概率为 $P = { \frac { \mathrm { C _ { 3 4 } ^ { 2 } } } { \mathrm { C _ { 6 6 } ^ { 2 } } } } = { \frac { 1 7 } { 6 5 } }$

(3) 根据题意可设正确的31个数据为 $\begin{array} { r } { | x _ { 1 } , x _ { 2 } , \cdots , } \end{array}$ x<sub>31</sub>，易知 $| \sum _ { i = 1 } ^ { 3 1 } x _ { i } + 1 5 6 = 3 2 \times 1 6 1$ ，可得 $\sum _ { i = 1 } ^ { 3 1 } x _ { i } = 4 9 9 6 .$ 所以原始数据平均值为 ${ \frac { 1 } { 3 2 } } { \bigg ( } \sum _ { i = 1 } ^ { 3 1 } x _ { i } + 1 6 5 { \bigg ) } = 1 6 1 . 2 8 1 2 5$ 由方差定义可得 ${ \frac { 1 } { 3 2 } } \biggl [ \sum _ { i = 1 } ^ { 3 1 } { ( x _ { i } - 1 6 1 ) ^ { 2 } } + { ( 1 5 6 - 1 6 1 ) ^ { 2 } } \biggr ] = 2 3 . 6 8 7 5$ 因此 $\sum _ { i = 1 } ^ { 3 1 } { \bigl ( } x _ { i } - 1 6 1 { \bigr ) } ^ { 2 } = \sum _ { i = 1 } ^ { 3 1 } x _ { i } ^ { 2 } - 2 \times 1 6 1 \sum _ { i = 1 } ^ { 3 1 } x _ { i } + 3 1 \times 1 6 1 ^ { 2 } = 7 3 3$ ，可得$\sum _ { i = 1 } ^ { 3 1 } x _ { i } ^ { 2 } = 2 \times 1 6 1 \sum _ { i = 1 } ^ { 3 1 } x _ { i } - 3 1 \times 1 6 1 ^ { 2 } + 7 3 3 = 8 0 5 8 9 4 ;$ 原始数据的方差为 ${ \frac { 1 } { 3 2 } } \left[ \sum _ { i = 1 } ^ { 3 1 } { \big ( } x _ { i } - 1 6 1 . 2 8 1 2 5 { \big ) } ^ { 2 } + { \big ( } 1 6 5 - 1 6 1 . 2 8 1 2 5 { \big ) } ^ { 2 } \right]$ $= \frac { 1 } { 3 2 } \bigg [ \sum _ { i = 1 } ^ { 3 1 } x _ { i } ^ { 2 } - 2 \times 1 6 1 . 2 8 1 2 5 \sum _ { i = 1 } ^ { 3 1 } x _ { i } + 3 1 \times 1 6 1 . 2 8 1 2 5 ^ { 2 } + 3 . 7 1 8 7 5 ^ { 2 } \bigg ]$ $\approx { \frac { 1 } { 3 2 } } \times 7 4 6 . 4 6 8 7 5 \approx 2 3 . 3 3$ 即原始数据的方差为23.33.
